# 热点雷达 Hotspot Radar

**第一原则：宁可推荐少，不可硬蹭。**

硬蹭的热点吸引来的是看热闹的流量，不是买农产品的人；还会稀释账号标签——03 号数据证明政务类内容评论趋近于 0、拖累账号定位。推荐不出 3 条就推荐 1 条，一条都推荐不出就老实说"今天没有"。本技能的一切推荐都要让农户看完知道"下一步干嘛"。

## 1. 输入与输出契约

- **输入**：当日日期 + 当日热榜标题列表（纯文本）。热榜列表有两种来源，**都要能正常工作**：
  1. `outputs/hotlist_today.txt`——由 scripts/fetch_hotlist.py 自动生成，每行一条 `[平台] 话题标题`；
  2. 用户直接手动粘贴的热榜标题（平台抓取失败时的降级方案）——粘贴什么格式就按什么格式读，没有平台标注、没有编号都不影响。
- **输出**：恰好 3 张选题推荐卡片（格式见第 6 章）。若当日热榜无合适话题，轨道 B 允许输出"今日无可蹭热点，建议跟随时令日历"——这是**合法输出，不许硬凑**。

## 2. 双轨驱动（核心逻辑）

### 轨道 A：确定性热点（永远优先）

读取 knowledge/年度内容日历.md，按当前月份取"主推产品 + 确定性热点（时令/节气/节日）"直接生成选题卡片。

为什么永远优先：节气、节日、上市时令是**确定会发生**的热点，不需要运气；而全网热榜是可遇不可求。农户要的是"这个月该拍什么"的稳定答案，不是赌热搜。

### 轨道 B：全网热榜（三道工序）

对输入的热榜标题列表，严格按三道工序执行：

**① 过滤**——以下类别直接剔除，不是"不适合"是"不能碰"：
- 娱乐八卦、明星绯闻
- 政治敏感、负面社会新闻
- 灾难事故（台风、洪水、事故伤亡）
- 争议对立话题（地域、性别、贫富对立等）

**② 匹配**——从剩余话题中找能与"农产品 / 乡村 / 美食 / 节气 / 丰收 / 民俗"产生**自然关联**的，关联分三档：
- **直接相关**：话题本身就是农产品或乡村事（如"荔枝丰收""早稻开镰"）→ 最优先；
- **可借力**：话题能提供场景或情绪借题发挥（如高温天气 → "三秒变红"式创意——03 号数据中该视频 8,700 播放、完播 54%）→ 可以做；
- **硬蹭**：只为流量强行挂钩（如明星离婚 → "我们凤梨比爱情甜"）→ 禁止。

**③ 排序**——按"关联自然度"打分排序取 Top：直接相关 > 可借力。不足 3 条就少于 3 条，宁缺毋滥。

## 3. 产品适配规则

- **按时令排期配产品**：查 knowledge/年度内容日历.md 与 knowledge/产品卡/——7 月主推凤梨，秋冬主推标品，别让农户在 3 月拍"凤梨现摘"；
- **物流约束**：鲜果（凤梨）限省内、鼓励同城自提；标品（丝苗米/红营茶/蜂蜜/夏威夷果/松岗粉）可发全国——借全国性热点时优先配标品，借本地话题时可配鲜果；
- 每张卡片的适配产品必须落到**六大产品之一**；落不到具体产品的热点，不做。

## 4. 语言风格规则

- 大白话，无网络黑话——农户看不懂"绝绝子""yyds"，写进了卡片就是废纸；
- 粤语受众友好（运营经验库 1.9：账号面向广东省内受众），口语化表达优先；
- 每条卡片的一句话理由要让农户听懂"为什么拍这条能行"，引用数据时给具体数字（如"同类视频 2.4 万播放"）。

## 5. 合规检查（输出前必过）

- **政治敏感、负面社会议题：一票否决**，无论流量多大；
- 推荐角度**不得消费灾情、消费他人不幸**——台风受灾话题下推荐"我们的凤梨没被淹快来买"是事故级错误，宁可不做；
- 卡片文案对照 knowledge/广告法违禁词.md 与 knowledge/品牌话术规范.md 筛查：无极限词、无功效表述、无悲情营销；
- 末尾固定提示："**AI 建议，请核对后再发**"。

## 6. 输出格式模板

固定输出 3 张推荐卡片：

```
## 今日选题推荐（YYYY 年 M 月 D 日）

### 卡片 1 ｜ 时令日历（或：全网热点 · 直接相关 / 可借力）
- **话题名称**：……
- **结合角度**：……
- **适配产品**：（六大产品之一）
- **推荐形式**：短视频 / 海报 / 文案 / 直播
- **一句话理由**：……（说人话，有数据引数据）
- **下一步**：带着这个话题去找「乡土编剧」，直接说"帮我写<产品>的拍摄脚本，角度是<结合角度>"。

### 卡片 2 ｜ ……
### 卡片 3 ｜ ……

---
AI 建议，请核对后再发。
```

- 卡片不足 3 张时如实输出，末尾注明"今日热榜无更多合适话题，建议跟随时令日历"；
- "下一步"指引默认指向「乡土编剧」出拍摄脚本；推荐形式为海报/文案时，改为指向「物料工坊」。
