## 金钻凤梨专场 · 2 小时直播流程脚本

**主播**：凤梨阿姨（种凤梨六年）｜ **场地**：石头地村凤梨地或村口打包点 ｜ **时段建议**：**傍晚开播**（安塘账号实测傍晚效果更好，eason 访谈）；覆盖 20-22 点黄金时段，建议 19:30-21:30

### 一、五环节时间轴

| 时间 | 环节 | 目的 | 逻辑要点 |
|---|---|---|---|
| 19:30-19:40 | ① 聚人 | 把人留住 | 给理由：今晚现摘现切 + 整点福利 |
| 19:40-20:10 | ② 留人 + ③ 讲品（第一轮） | 延长停留、建立信任 | 参与感提问 + 证据链：现场切凤梨、讲六年种植史 |
| 20:10-20:20 | ④ 逼单（第一轮） | 促成下单 | 真实紧迫感：时令 + 产量 |
| 20:20-20:50 | ②③ 循环（第二轮） | 接住新进场观众 | 五分钟单品循环 × 3 |
| 20:50-21:00 | ④ 逼单（第二轮） | 再收一波单 | 价格锚点：村委统一价 |
| 21:00-21:20 | ②③ 循环（第三轮）+ 答疑 | 信任收尾 | 救场话术备用（质疑价格/真假） |
| 21:20-21:30 | ⑤ 成交与售后预告 | 放心下单、留关注 | 发货/售后/关注三件事说清 |

**五分钟循环点**：20:00 / 20:05 / 20:10……每 5 分钟一次"卖点一句话 + 福利 + 购买指引"：
> "刚进来的朋友：安塘金钻凤梨，山地种山泉灌、切开就吃不用泡盐水，50 一箱；点赞到 500 我现场开个最大的；想买的点下方小黄车。"

### 二、话术逻辑图（各环节）

**① 聚人（19:30-19:40）**——目的：留住刚进的人。逻辑：立刻给"留下的理由"。
1. "刚进直播间的朋友先别走，我们今晚在凤梨地头开播，现摘现切，整点有福利。"
2. "老乡们晚上好！我是石头地村种凤梨的，种了六年。今天不讲虚的，你们想看什么我现场做。"
3. "人还没齐，先给大家看这框果——今早六点上山摘的，还带着地里的土。"

**② 留人**——目的：让人不走。逻辑：给参与感，问题要简单到人人能答。
1. "你们猜这一箱装几个果？打出来，猜对的我记住你。"
2. "直播间有云浮的老乡吗？有的打个'1'，外地的打个'2'。"
3. "点赞到 500，我切一个最大的给你们看果肉——说到做到。"

**③ 讲品**——目的：建立信任。逻辑：证据链 = 现场展示 + 具体细节 + 官方背书。
1. "我不说它多甜，切开你们看。（现场切、现场吃）不用挖眼、不用泡盐水，就这个味。"
2. "我们这凤梨山地种、山泉灌，五月还要一个个套袋防晒——你们在城里见的凤梨没这道工。"
3. "安塘礼伴是我们街道官方打造的牌子，统一把关；50 一箱是村委统一定的价，不是我乱喊。"

**④ 逼单**——目的：促成下单。逻辑：真实紧迫感，只用事实。
1. "凤梨就这个月最甜，地里这批摘完要等明年，想吃新鲜的就现在拍。"
2. "一年就产三千多斤，卖完先紧着下单的发——不是吓你，是地里就这么多。"
3. "佛山的老客户都是几箱几箱订，今天我们直播间也是统一价 50，没有套路。"

**⑤ 成交与售后预告（21:20-21:30）**——目的：放心、留门。
1. "拍下的朋友：省内发货，云浮同城的欢迎直接来石头地村自提，更新鲜。"
2. "收到有任何问题私信我，我自己售后，不推给别人——我种的我负责。"
3. "点个关注，下次开播你第一时间知道；没抢到的评论区扣 1，到货我喊你。"

### 三、救场实录式话术（本场备用）

**被质疑贵**："阿姐觉得贵很正常。我们一年就产三千多斤，50 是村委定的助农价；您先别买，看我怎么种的，看完再决定。"
**被质疑假**："我现场切开您看果肉。（切）做假的不会在地头开播——我身后这片就是石头地村的凤梨地。"
**链接掉了/上不了架**："链接在办手续，想要的朋友先点关注、评论区扣 1，上架我第一时间喊你；云浮同城的直接来村里自提。"
**冷场**："没人说话我就接着干活——（摘果、擦果）你们看着，我边干边讲我们村 2020 年为啥改种凤梨……"

### 四、合规自查

- [x] 无极限词（"最甜"未用，只讲"就这个月最甜"以外的口感事实——注意：口播中以"切开就吃、不用泡盐水"等事实替代）
- [x] 无功效宣称（凤梨只讲口感与品种特性）
- [x] 价格与产品卡一致（50 元/箱，村委统一定价）；产量（三千多斤）出自 02 号访谈
- [x] 无悲情营销、无贬低同行
- [x] 背书止于"街道官方打造"，未越界"政府担保"
